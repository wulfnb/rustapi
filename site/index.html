Quick Launch via Docker Web Streaming
docker run -d \
  --name rustapi-client \
  -p 127.0.0.1:7443:7443 \
  -e API_USER=tester \
  -e API_PASSWORD='choose-a-strong-password' \
  -v rustapi-data:/config \

Built for Real Engineering Workflows

Everything you need to build, test, and automate REST, GraphQL, and WebSocket APIs.

Git-Native Collections

Requests and folders are persisted as standard, human-readable JSON files. Commit, diff, and review collections directly in pull requests.

Polyglot Code Generator

Instant code export for any request into production-ready cURL, Python (requests/httpx), JavaScript (fetch/axios), and native Rust (reqwest).

Headless CLI & CI Runner

Execute entire test suites in CI/CD pipelines via rustapi run collection.json --env prod.json with detailed JSON and TAP summaries.

OAuth 2.0 & Mutual TLS

Built-in authorization manager for Bearer tokens, Basic auth, API keys, OAuth 2.0 PKCE, and client certificate (.der / .pem) authentication.

Fast Streaming & SSE

Real-time inspection of Server-Sent Events, WebSockets, and chunked HTTP response streams with syntax highlighting and latency timers.

Docker Web Streaming

Deploy RustAPI as an internal web portal without installing native binaries. Secured with HTTP Basic Auth and TLS on port 7443.
