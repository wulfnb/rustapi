# RustAPI application icon

The **Hyper-Bolt Brackets** icon (two code brackets `{ }` fusing into an energetic vertical lightning pulse / bidirectional data transfer arrow on dark carbon slate) is the visual identity for RustAPI across all desktop platforms and the web.

## Design and palette

- **Visual Concept**: Code brackets `{ }` framing an energized bidirectional lightning transfer arrow, symbolizing instantaneous request/response exchange and sub-50ms execution.
- **Palette**:
  - Background: Carbon fiber slate (`#12131A` to `#0E0D14`)
  - Accent Pulse: Crimson-orange (`#FF3B30`), ember amber (`#FF9500`), and solar gold (`#FFD60A`)
  - Bracket Framing: Graphite metal (`#4B485A`)

## Files

- `rustapi-icon-source.png`: Original master artwork.
- `rustapi-icon.png`: 1024 px master export.
- `rustapi-icon-256.png`: Embedded native window and sidebar icon.
- `RustAPIIcon.icns`: macOS 16–1024 px / Retina exports used by macOS application bundles.
- `RustAPIIcon.ico`: Windows multi-resolution executable icon (16–256 px), embedded into `rustapi.exe` and Inno Setup installer.
- `site/favicon.png`: 64 px web icon.
- `site/apple-touch-icon.png`: 180 px web icon.
- `site/logo.png`: 256 px header and branding mark.

Generated via `scripts/generate-icons.py`.
